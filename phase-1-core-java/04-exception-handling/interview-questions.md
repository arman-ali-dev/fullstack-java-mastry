## Must Prepare

1. Explain the Java exception hierarchy.
2. What is the difference between `Exception` and `Error`?
3. Should you catch errors like `StackOverflowError` or `OutOfMemoryError`?
4. What is the difference between checked and unchecked exceptions, and why did Java design them this way?
5. How does the `try-catch-finally` flow work?
6. Can you have `try` without `catch`?
7. Does the `finally` block always execute? In which cases does it not?
8. What does a method return if both the `try` block and the `finally` block contain a `return` statement?
9. Why must specific `catch` blocks come before general ones?
10. What is multi-catch (Java 7+)?
11. What is the difference between `throw` and `throws`?
12. How do you create a custom exception, and how do you decide between making it checked or unchecked?
13. What is try-with-resources, how does it work with `AutoCloseable`.
14. In what order are resources closed?
15. What is exception chaining?
16. How does an exception propagate up the call stack if it is not caught?
17. What are the common causes of `NullPointerException`, and how do you prevent it?
18. What are the rules for exceptions when overriding a method (checked vs unchecked in the child method)?
19. What are suppressed exceptions in try-with-resources?
20. Why should exceptions not be used for normal flow control?
21. What happens if an exception is thrown inside the finally block?
22. What is InterruptedException, and how should we handle it properly?
23. What is the difference between ClassNotFoundException and NoClassDefFoundError?
