## IMPORTANT PATTERNS TO KNOW

These patterns repeat across many problems. Once you know the pattern, applying it to new problems becomes easy.

```
Pattern                     Problems it solves
----------------------------|------------------------------------------
Sliding Window              Subarray/substring problems with constraint
Two Pointers                Sorted array problems, pair finding
Fast and Slow Pointers      Linked list cycle, middle element
HashMap for frequency       Anagram, duplicates, frequency counting
Prefix Sum                  Subarray sum problems
Monotonic Stack             Next greater, previous greater, histogram
BFS                         Shortest path, level order, connected components
DFS + Backtracking          All paths, all combinations, permutations
Binary Search on Answer     Min/max optimization problems
Topological Sort            Dependency ordering, course schedule
Union Find                  Connected components, cycle detection
```
