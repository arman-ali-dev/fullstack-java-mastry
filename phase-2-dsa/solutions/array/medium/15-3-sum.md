# 3 Sum

Let me restate the problem. We are given an array of integers. We need to return all unique triplets whose sum is equal to 0, where the three elements come from distinct indices.
<br>
Let me clarify a few things. Can the array have duplicates and negative numbers? Can it be empty? Should I return a list of lists of integers? Does the order of triplets matter? Can I sort the input array?
<br>
The brute force approach is to use three nested loops to check every triplet, where j starts from i plus 1 and k starts from j plus 1, so the indices are distinct. If the sum is zero, I sort the triplet and add it to a HashSet, so duplicate triplets are removed. After the loops, I convert the set into a list and return it.
<br>
Time complexity is O(n³) because of three nested loops. Space complexity is O(n) for the set, ignoring the output.
<br>
But this is too slow, so we can optimize using sorting and two pointers.
<br>
We can optimize this using sorting and two pointers. I sort the array first, so that two pointers work and duplicate values come together. Then I traverse the array with i from 0 to n minus 3. If i is greater than 0 and nums[i] is equal to nums[i minus 1], I skip the iteration, to avoid duplicate triplets. Then I initialize left with i plus 1 and right with n minus 1.
<br>
I run a while loop with the condition left less than right. I calculate the sum of nums[i], nums[left] and nums[right]. If the sum is zero, I add the triplet to the list and move left forward and right backward. Then I move left forward while left is less than right and nums[left] is equal to nums[left minus 1], to skip duplicates. If the sum is greater than zero, I need a smaller value, so I move right backward. Otherwise, I need a larger value, so I move left forward.
<br>
Time complexity is O(n²) because sorting is O(n log n), and the outer loop runs n times with two pointers taking O(n) each, so O(n²) dominates. Space complexity is O(1) if we ignore the output list because I use only three pointers.”

### Code

```java
class Solution {
    public List<List<Integer>> threeSum(int[] arr) {
        Arrays.sort(arr);
        List<List<Integer>> ans = new ArrayList<>();

        int n = arr.length;

        for (int i = 0; i < n; i++) {
            if (i > 0 && arr[i] == arr[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = n - 1;

            while (left < right) {
                int sum = arr[left] + arr[right] + arr[i];

                if (sum == 0) {
                    ans.add(List.of(arr[left], arr[right], arr[i]));
                    left++;
                    right--;

                    while (left < right && arr[left] == arr[left - 1]) {
                        left++;
                    }
                } else if (sum > 0) {
                    right--;
                } else {
                    left++;
                }
            }
        }

        return ans;
    }
}
```
