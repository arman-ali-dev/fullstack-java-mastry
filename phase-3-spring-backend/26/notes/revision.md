Java and MySQL are separate programs
- A Java application normally runs inside the JVM:
- MySQL runs as a separate server process

JDBC stands for Java Database Connectivity. It is a standard Java API used to communicate with relational databases.

- JDBC API The JDBC API defines the contracts used by Java code.
- JDBC driver The JDBC driver provides the database-specific implementation of the JDBC contracts.
- For MySQL, the official driver is MySQL Connector/J.
- PostgreSQL PostgreSQL JDBC Driver
